# Python Sales Calculator

Programa desenvolvido em Python para simular o cálculo do valor de uma compra de acordo com a forma de pagamento escolhida pelo cliente.

📋 Sobre o projeto

Este projeto foi desenvolvido como parte dos estudos de Python, com foco na prática de lógica de programação e estruturas condicionais.

O programa permite informar o valor de uma compra e selecionar uma forma de pagamento, aplicando as respectivas regras de desconto ou parcelamento.

⚙️ Funcionalidades

- Informar o valor total da compra;
- Selecionar a forma de pagamento;
- Aplicar desconto para pagamento via boleto;
- Aplicar desconto para pagamento à vista em compras elegíveis;
- Permitir o parcelamento da compra no cartão de crédito;
- Exibir os valores calculados com formatação monetária.

 🧠 Conceitos praticados

- Variáveis;
- Entrada de dados com `input()`;
- Conversão de tipos com `int()` e `float()`;
- Estruturas condicionais `if`, `elif` e `else`;
- Operadores matemáticos e relacionais;
- Cálculos com valores monetários;
- Formatação de strings com f-strings;
- Formatação numérica com `:.2f`;
- Controle de fluxo e lógica de programação.
